# อัปเดตข้อความวินิจฉัย Facebook OAuth

แพตช์นี้แยกข้อผิดพลาดเครือข่ายออกจากการตอบกลับของแพลตฟอร์ม และแสดงเฉพาะชื่อโฮสต์ ขั้นตอน API และระยะเวลา ไม่มี URL เต็ม, Token, Secret หรือข้อความดิบจาก cURL

## ติดตั้งบนโฮสติ้ง

1. สำรองไฟล์ `Integrations.php` และ `controller.php` จากโฟลเดอร์ `studio-private/app` ไว้ในพื้นที่ส่วนตัว
2. อัปโหลดไฟล์สองรายการในแพตช์ทับชื่อเดิมที่ `Home directory/studio-private/app` ซึ่งอยู่นอกโฟลเดอร์เว็บไซต์ `krusomkhuan.com`
3. ไม่ต้องแก้ Config และไม่ต้องอัปเดตฐานข้อมูล
4. กลับ Studio กด Connect / Reconnect Facebook เพื่อเริ่มใหม่ อย่ารีเฟรช callback เดิม
5. ส่งข้อความผิดพลาดใหม่ให้ผู้ดูแลระบบวิเคราะห์ต่อ

## อ่านข้อความ

- `token`: คำขอแลกหรือขยายอายุโทเค็น (ป้ายนี้ไม่ได้แยกสองคำขอ)
- `identity`, `permissions`, `pages`: คำขอข้อมูลผู้ใช้ สิทธิ์ หรือรายชื่อเพจ
- `dns`, `connect`, `tls`, `response`, `transfer`: ขั้นตอนโดยประมาณจากเวลาที่ cURL รายงาน ไม่ใช่ข้อสรุปว่าอุปกรณ์ใดเสีย

คงเวลารอเดิม (เชื่อมต่อ 5 วินาที / รวม 20 วินาทีต่อคำขอ) และการตรวจสอบ TLS ไว้ ไม่ส่งคำขอซ้ำอัตโนมัติ แพตช์นี้ยังไม่ยืนยันหรือแก้สาเหตุเครือข่ายบนโฮสติ้ง

ตรวจ syntax PHP และทดสอบข้อมูลสังเคราะห์ 5 กรณีว่ารายละเอียดไม่แสดงข้อมูลลับแล้ว ยังไม่ได้ทดสอบกับโฮสติ้งจริง
